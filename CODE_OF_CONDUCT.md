# Code of Conduct

## Our Commitment
Our team commits to creating a respectful, inclusive, and collaborative environment.

## Expected Behaviour
- **Respectful Communication**: All team members communicate professionally
- **Clear Documentation**: Document all work and decisions
- **Timely Code Reviews**: Review pull requests within 24 hours
- **Equal Participation**: All voices are heard and valued
- **Continuous Learning**: Support each other's growth
- **Version Control Discipline**: Follow GitFlow branching strategy

## Accountability
Team members are accountable for maintaining these standards.
